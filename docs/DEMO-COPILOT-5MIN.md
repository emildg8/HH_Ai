# Демо суфлёра HH Ai — 5 минут

Краткий сценарий, чтобы **рассказать и показать** живой суфлёр без погружения в код.

---

## За 30 секунд до показа

```powershell
cd D:\Dev\apps\hh-ai
npm run devops:dashboard
# В другом окне (опционально Desktop):
npm run desktop:launcher
```

Проверка (30 с):

```powershell
npm run test:copilot
```

Ожидаемо: `[test:copilot] OK` (10 тестов).

Откройте в браузере: **http://localhost:3849** → модалка **«Собеседования»** (хаб E).

---

## Слайд 1 — Зачем это (45 сек)

**Что сказать:**

> HH Ai — не отдельный «читерский» copilot за $90/мес, а **суфлёр внутри воронки hh.ru**: от слота на собес (корзина E) до офера (F).  
> Подтягивается **ваше резюме, вакансия, план собеса** — не нужно заново загружать PDF.  
> Данные остаются **на вашем ПК**; overlay через Desktop **не попадает в шаринг экрана** (если не шарите весь экран).

**Показать:** хаб собеседований — плитки воронки A–F, список слотов E.

---

## Слайд 2 — Путь «К собесу» (90 сек)

**Что сказать:**

> Один понятный путь: **К собесу** → мастер из 4 шагов → одна главная кнопка **«Поверх + живой»**.

**Показать по шагам:**

1. В строке слота E нажать **«К собесу»** — откроется вкладка подготовки.
2. **Мастер:** контекст слота → звук (микрофон в Настройки → Суфлёр) → таблица Zoom/Телемост → старт.
3. **«Что подтянется в ответы»** — модалка с CV, RAG, prep (не toast).
4. **«Сценарий поверх»** — второе окно с планом (prep), основное — live-ответы.

**Не нажимать live**, если нет созвона — достаточно UI.

---

## Слайд 3 — Репетиция без Zoom (60 сек)

**Что сказать:**

> Перед боем можно прогнать **запись** или мини-транскрипт — суфлёр меняется на вопросах интервьюера.

**Показать:**

1. Вкладка **«Репетиция»**.
2. **«Прогон на записи»** (fixture уже в проекте) — список вопросов в debug-панели.
3. Кнопка **«Репетиция → суфлёр»** — overlay (Desktop) или окно в браузере.

---

## Слайд 4 — Во время собеса (60 сек)

**Что сказать:**

> На созвоне: loopback ловит вопрос интервьюера → **tier1 за ~1 с** (шаблон) → tier2 уточняет.  
> Ответы — **буллеты (scaffold)**, не абзац для зачитывания.  
> **Ctrl+Shift+S** — «ответил сам», **Ctrl+Enter** — обновить ответ, **Ctrl+Shift+H** — спрятать overlay.

**Показать (если есть Desktop + микрофон):**

1. **«Поверх + живой»** → вкладка **«Во время»** — badge «Слушаю…» / «Ответ».
2. Иначе — только вкладку и hotkeys на экране.

---

## Слайд 5 — После собеса → офер (45 сек)

**Что сказать:**

> Stop → автоматически вкладка **«После»**: оценка 1–5, debrief, **follow-up в чат hh**, кнопки **«Жду ответ» / «Переговоры»** в offer-tracker.  
> Offer-guard ловит токсичный тон и несостыковки с тем, что вы уже сказали.

**Показать:** вкладка «После» — рейтинг, блок debrief, кнопки follow-up.

## Запасные ответы на вопросы (30 сек)

| Вопрос | Ответ |
|--------|--------|
| Это как Sufler/Final Round? | Да, live overlay, но **+ воронка hh, prep из слота, post follow-up**, $0 self-hosted |
| Видно на шаринге? | **Нет**, если Desktop + не шарить весь экран; есть чеклист в мастере |
| Нужен интернет для LLM? | Tier1 часто без LLM; tier2 — ваш OpenRouter/локальный LLM |
| Легально? | Инструмент подготовки; ответственность за правила компании — на кандидате |

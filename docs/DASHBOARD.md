# Дашборд HH Ai

**Версия:** 2.0.1 · URL по умолчанию: **http://127.0.0.1:3849**

## Запуск

```bash
npm run dashboard
# или
npm run devops:dashboard
```

Сервер работает, пока открыт терминал. После обновления кода фронта — **Ctrl+F5** в браузере.

Порт: `DASHBOARD_PORT` в `.env` (по умолчанию `3849`).

## Сайдбар (CRM, 2.0.1)

| Блок | Назначение |
|------|------------|
| **Полный / Кратко** | Кратко — только «Утренний цикл», вкладки очереди и навигация |
| KPI + **Аналитика** | Мини-воронка; модалка — графики по всем `vacancies*.json` |
| **Утренний цикл** | sync откликов → кэш в очередь → чаты (+ опц. harvest) |
| **Сбор / Батч** | Harvest и батч авто/ручной |
| Быстрые кнопки | Отклики, Чаты, Импорт, Резюме |
| **Сервис** / **Настройки** | Остальные операции; лимиты и фильтры списка |

Поиск в шапке: вакансия, компания, резюме, чат, письмо. Фильтры балла/сортировки — **Настройки → Список**.

## Вкладки очереди (список)

| Раздел | Назначение |
|--------|------------|
| Очередь | Вакансии с оценками, фильтры, approve/reject |
| Без анкет | Подмножество для батча без остановки на анкетах |
| Анкета | Вакансии с анкетой работодателя, ответы, probe |
| Скрытые | Отфильтрованные по роли (senior, 1С, …) |

Данные: `data/vacancies-<profile>.json` (путь задаёт профиль, см. [CONFIG.md](CONFIG.md)).

## Карточка вакансии

- Оценки LLM (`scoreOverall`, теги, причины).
- Генерация / правка / **утверждение** сопроводительного.
- **Отклик в браузере** — запуск `hh-apply-chat` для одной вакансии.
- Probe анкеты — `devops:probe-questionnaire` с UI.
- Отклонение с комментарием → опционально `reject-similar`.

## Анкета работодателя

1. Вопросы из батча, probe или эвристики harvest.
2. Поля в модалке: текст, выбор варианта (`questionnaire-choice.mjs`).
3. **Сохранить** — ответы в JSON записи.
4. Авто-подстановка при отклике, если DOM совпал.

Флаги: `HH_QUESTIONNAIRE_AUTO`, `HH_QUESTIONNAIRE_LLM` — см. [CONFIG.md](CONFIG.md).

## Батч из дашборда

1. Выберите область (**«Без анкет»** для массового прогона).
2. Задайте лимит / min score (если есть в UI).
3. Старт батча — прогресс и лог в реальном времени.
4. Пауза / стоп — `data/batch-control.json`.

См. [BATCH.md](BATCH.md).

## UI (2.0)

| Настройка | Описание |
|-----------|----------|
| Масштаб UI | 85–115%, модалки вне zoom |
| Плотность карточек | compact / medium / full |
| Тонкая настройка карточек | ширина колонок, шрифт (`ui-card-tuning`) |
| Тема | светлая / тёмная |
| Локальные пресеты | скопировать `local-dashboard-defaults.example.mjs` → `local-dashboard-defaults.mjs` (в git не входит) |

Настройки дашборда частично в `config/preferences.json` (`dashboardUiScale`, `cardDensity`, …).

## API и данные

Сервер: `scripts/dashboard-server.mjs`. Статика: `dashboard/public/`.

Не открывайте дашборд в интернет без защиты — локальный инструмент, сессия hh.ru на той же машине.

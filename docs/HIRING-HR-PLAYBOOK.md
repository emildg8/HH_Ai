# HR-playbook: DevOps junior+/middle (L2 → DevOps)

Правила отбора и отклика для профиля: банковский L2, вилка 150–180k ₽, удалёнка/гибрид Москва.

## Tier каналов

| Tier | Канал | Действие |
|------|-------|----------|
| **A** | ATS компании, hh &lt;72 ч in-house | Приоритет в дашборде, авто-отклик (только hh) |
| **B** | Habr, тёплый чат после просмотра | Ручной отклик + сильное письмо |
| **C** | Telegram-агрегаторы, hh старая, аутстафф | Ingest с пониженным score |
| **D** | EN jobboards (волна 2) | Отдельный профиль prefs |

**Правило:** 40 точных откликов в A/B лучше 150 размытых в C.

## Письмо за 15 секунд

Структура: **hook → факт → цифра → CTA**

1. Не «Я откликаюсь на вакансию…»
2. Один кейс под JD (K8s, CI/CD, мониторинг)
3. Минимум одна цифра (SLA, инциденты, релизы)
4. Без: «командный игрок», «стрессоустойчивый», «в связи с вышеизложенным»

## Резюме vs письмо

- Заголовок: DevOps / SRE / инженер инфраструктуры
- «О себе»: мост L2→DevOps + 1 метрика
- Письмо ≠ пересказ резюме

## Тайминг

- Вакансия &lt;72 ч → boost `sourceQualityScore`
- Старше 14 дней → tier C / skip
- Follow-up: max 1 / 7 дней

## Политики в HH Ai

- Дубль компании 30 дней: `apply-red-flags.mjs`
- Зарплата: `config/hr-screening-answers.example.json`
- Перед tier-A harvest: `npm run devops:raise-resumes`

## Habr vs hh

| | hh | Habr |
|---|-----|------|
| Аудитория | HR + иногда техлид | Техлид / тимлид |
| Письмо | Короткое | Техдетали уместны |
| Отклик | Авто | Ручной + черновик |

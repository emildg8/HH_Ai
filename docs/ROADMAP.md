# Roadmap HH Ai / hh-ru-apply

Исходная цель: **меньше ручного труда** на откликах hh.ru при **контроле качества** (оценка вакансий, письма, анкеты), с учётом опыта приглашений и отказов.

Текущая версия: **1.0.0** (DevOps-профиль Emil, дашборд, harvest, LLM, анкета).

---

## Фаза 1 — Фундамент (сделано в 1.0)

- [x] Очередь вакансий, скоринг (вакансия + CV), дашборд
- [x] Сопроводительные: черновик → утверждение → эталоны стиля
- [x] Отклик Playwright, анкета работодателя, probe
- [x] Профили `HH_PROFILE`, бэкапы, публичный экспорт, SECURITY
- [x] Отклонение похожих ролей, фильтры senior/1С/dev

---

## Фаза 2 — Качество и меньше ручных правок (Q2–Q3 2026)

### Генерации (письма и анкета)

- [ ] **Feedback loop:** автоматически подмешивать утверждённые письма и ответы с **приглашениями** (тег `invited` в дашборде)
- [ ] A/B вариантов письма с метрикой «открыли / ответили» (если доступно с hh)
- [ ] Шаблоны по типу вакансии (SRE / platform / DBA) из `preferences` + few-shot
- [ ] Валидация анкеты: не отправлять generic «Текстовое поле», повторный probe из CI

### Автоматизация

- [ ] **Умный batch:** лимит откликов/день, паузы, стоп при капче
- [ ] Очередь «отклик завтра» при исчерпании OpenRouter
- [ ] Webhook/Telegram: «собрано N вакансий ≥50», «нужна анкета»
- [ ] Авто-rescore ночью только для `pending` без скора

### Безопасность

- [ ] Шифрование `data/session` опционально (пароль на профиль)
- [ ] Pre-push hook: `export:public` + grep секретов
- [ ] Аудит логов: не писать полный текст письма в лог при `HH_LOG_REDACT=1`

## Фаза 4 — Интеллект и опыт собеседований (2027+)

- [ ] База «вопрос с собеса» → подсказка в анкете и письме
- [ ] Связь вакансии с календарём интервью
- [ ] Рекомендация: отклонить / отложить по истории похожих компаний
- [ ] Локальная модель по умолчанию (Ollama) с fallback OpenRouter

## Метрики успеха

| Метрика | Цель |
|---------|------|
| Доля откликов без ручного редактирования письма | > 60% |
| Время от harvest до отклика (медиана) | < 5 мин на вакансию |
| Ложные «подходит» (потом отклонили сами) | < 15% |
| Утечки секретов в git | 0 |

- Массовый спам без лимитов

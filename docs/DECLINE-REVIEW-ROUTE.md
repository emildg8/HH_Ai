## Сценарий (5 шагов, ~10 мин)

```text
1. Синк     → Emil: `devops:sync-chats:emil` · Настя: `devops:sync-chats:anastasia`
               (с 19.07 sync-chats тянет и **статусы** списка «Отклики», в т.ч. Отказ → `hhSiteState: declined`)
               запас: `devops:anastasia-sync-responses` / `devops:sync-responses`
2. Карточка → vacId, дата отклика→отказа, трек резюме, письмо из store
3. Класс    → таблица ниже (один основной класс)
4. Действие → одна правка процесса/таргета/письма ИЛИ «архив, без правки»
5. Фиксация → строка LEARNING-LOG только если класс повторился ≥2 раза
```

### Кулдаун компании (анти-дубль, не «разбор отказа»)

Повторный **авто**-отклик на ту же компанию: **7 дней** (`DUPLICATE_COMPANY_COOLDOWN_DAYS`, hunt-day).  
После шаблонного отказа — **тот же 7д**, не «недели молчания», если нет отдельного ME-freeze (как Сбер до Kandinsky).  
**Исключение ГНИВЦ (Настя):** после СПОТ + ВЭД — пауза **7–10д** (`employer-blacklist.json`, until ~29.07), не дольше; без сильного Oracle/ВЭД-fit.  
Отказ после **техэтапа / реферала** (ГНИВЦ СПОТ) — отдельный debrief; кулдаун на hh-отклики в ту же фирму всё равно держим.

## Классы причин → действие

| Класс | Признаки | Действие | Не делать |
|-------|----------|----------|-----------|
| **A. Шаблон / без причины** | «не готовы пригласить», «спасибо за интерес», нет стека/формата | Архив. Сверить JD hard-req vs письмо. Если gap (напр. прод-K8s) — **таргет/niche**, не переписывать уже ушедшее письмо | Массово «улучшать» все письма |
| **B. Конкретика по стеку** | «нужен K8s/Ansible/…», «мало опыта X» | Framing/мост в **будущих** письмах; при E0 — не auto-ship нишу | Врать commercial K8s |
| **C. Формат работы** | office/гибрид вне политики; робот «да» на офис | Gate / robot office-guard (уже: Консалт Плюс) | Авто-да на office |
| **D. Позиция закрыта / внутренний** | «вакансия закрыта», перевод | Архив, без урока по скиллу | Менять CV |
| **E. Overqual / лид-тон** | отказ &lt;24ч на IC-JD; в письме 14+/руководил 20+ | `letter-cv-framing` / opening | Усиливать лид на L2 |
| **F. Процесс (голое / чужое CV / дубль)** | без письма; неверный track; 2 чата | APPLY-CHAIN / picker / №85 | «Ещё один отклик другим резюме» |
| **G. Скрининг-анкета / робот** | отказ после анкеты; неверные ответы | Probe answers; office-guard | Угадывать «да» |
| **H. Конкуренция / ATS объём** | высокий наш score, шаблон через 1–3 дня, K8s в JD | Принять; темп 8–10/день; не раздувать серию из-за одного отказа | Panic mass apply |

**Правило:** один отказ = один класс. При сомнении между A и H → **A/H**, действие «архив + смотреть hard-req».

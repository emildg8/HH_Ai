# Система карточек очереди (QC v1)

**Связь с дашбордом:** карточки — **Track 2** в [DESIGN-SYSTEM-PLAN-2026-06.md](DESIGN-SYSTEM-PLAN-2026-06.md) v3.0; палитра `--cq-*` выравнивается с `--hh-*` / `--ui-*` (задачи DS-02, DS-28). Индекс UX: [DESIGN-ECOSYSTEM-INDEX.md](DESIGN-ECOSYSTEM-INDEX.md).

## Цель

Один визуальный язык для трёх плотностей просмотра: пользователь переключает **Краткий → Средний → Полный**, не меняя «стиль» отдельно.

## Принципы UX

1. **Одна карточка — одно действие**: клик по строке/плитке → полная карточка в модалке.
2. **Прогрессивное раскрытие**: краткий (сканирование) → средний (контекст) → полный (работа).
3. **Фиксированная панель действий**: hh · › · × — всегда в слотах одного размера, без наложений.
4. **Балл — пилюля**, не круг: одинаково в кратком и среднем.
5. **Прокрутка** — у `#workspace-list-viewport`, список не обрезается.

## Токены (`--qc-*` / `--cq-*`)

| Токен | Назначение |
|-------|------------|
| `--cq-surface` | Фон карточки (все три вида) |
| `--cq-surface-border` | Рамка карточки |
| `--cq-score-high-*` / `--cq-score-low-*` | Балл: зелёный / жёлтый |
| `--cq-good-bar` / `--cq-warn-bar` / `--cq-accent-bar` | Левая полоска статуса |
| `--cq-foot-bg` | Панель «Отклик / Решение» |
| `--cq-list-bg` | Фон контейнера списка (краткий) |
| `--qc-*` | Алиасы для плиток → `--cq-*` |

Источник: `design-tokens.css`. Семантика: `--ds-good`, `--ds-warn`, `--ds-accent`.
## Три вида

### Краткий (`tile-compact`)

**Задача:** быстро пролистать 100+ вакансий.

```
[балл]  название · компания · зарплата     [статус] [hh][›][×]
```

- Одна строка, список в рамке.
- Статус — одна короткая метка.
- Действия — только в `.card-tile__actions` (3 слота).

### Средний (`tile-medium`) — **зафиксированный вид (v1, 2026-05)**

**Задача:** полные карточки в **сетке** — можно откликаться и принимать решение без модалки.

```
┌─────────────────────────────┐  ┌─────────────────────────────┐
│ (94) DevOps-инженер      ×  │  │ (88) SRE Engineer        ×  │
│ компания · зарплата         │  │ ...                         │
│ • факты · суть · теги       │  │                             │
│         … свободное …       │  │                             │
│ [риски]                     │  │ [риски]                     │
├─────────────────────────────┤  ├─────────────────────────────┤
│ ОТКЛИК  [Авто-отклик]      │  │ ОТКЛИК  [Авто-отклик]      │  ← одна линия
│ РЕШЕНИЕ Подходит / Нет     │  │ РЕШЕНИЕ Подходит / Нет     │
└─────────────────────────────┘  └─────────────────────────────┘
```

- Рендер через **`renderCard()`** + класс `.card--layout-medium` (не плитки).
- Список: **CSS grid** (`vacancy-grid--medium`), ширина колонки **`--card-col-w`** (дефолт **30rem**, ползунок в **Настройки → Масштаб и тема → Ширина карточек**).
- **Без внутренних скроллов** — контент растёт по высоте; прокрутка только у `#workspace-list-viewport`.
- **Футер прижат к низу**: карточки в строке сетки растягиваются (`height: 100%`), `card-body` flex-grow, риски — `margin-top: auto`, панель **Отклик / Решение** (`.card-foot--v4`) всегда внизу — кнопки выровнены в ряд.
- Шапка: круглый бейдж балла слева, заголовок справа; чат и длинное описание скрыты.
- Стили: **`dashboard-cards.css`** (блок «Средний»), не трогать без явной задачи на регрессию.
### Полный (`expanded`)

Без изменений — существующая `.card`.

## Разметка (единый шаблон)

```
.card-tile
  .card-tile__score-ring > .card-tile__score
  .card-tile__body
    .card-tile__hit > title, meta, hint
    .card-tile__foot > status-chips, .card-tile__open
  .card-tile__rail
    .card-tile__badge
    .card-tile__actions > hh, chev, dismiss
```

## Поведение (v1.1)

- Открытая в модалке вакансия подсвечивается (`.card-tile--active`).
- Средний вид: подсказка с меткой (Риск, Анкета, …) + текст.
- Узкая строка краткого вида: заголовок и мета в две строки (container query).
- Touch: крупнее зоны hh / ×; hh в кратком виде всегда видна.

# Происхождение проекта

**HH Ai** — форк и развитие открытого проекта:

| | |
|---|---|
| **Базовый проект** | [Steev193/hh-ru-apply](https://github.com/Steev193/hh-ru-apply) |
| **Стек** | Node.js, Playwright, локальный дашборд |
| **Лицензия базы** | MIT (см. [LICENSE](../LICENSE)) |

## Что добавлено

- Профили поиска (`HH_PROFILE`), расширенный дашборд (анкета, темы, масштаб UI, плотность карточек)
- LLM-оценка, batch-отклики, отклонение похожих вакансий
- Бэкапы, релизные архивы, публичный экспорт (`npm run export:public`)

При публикации форка сохраняйте указание на исходный репозиторий и лицензию MIT.

# Происхождение проекта

**HH Ai** — самостоятельный проект. Канонический репозиторий:

**[github.com/emildg8/HH_Ai](https://github.com/emildg8/HH_Ai)**

## Идея-основа

Изначально вдохновлён открытым [Steev193/hh-ru-apply](https://github.com/Steev193/hh-ru-apply) (Node.js + Playwright + локальная автоматизация hh.ru, MIT). С версии **2.0** код, дашборд, батч, анкеты, профили и документация **сильно переработаны** — это уже отдельный продукт, а не форк для синхронизации с тем репозиторием.

| | |
|---|---|
| **Идея-основа (исторически)** | [Steev193/hh-ru-apply](https://github.com/Steev193/hh-ru-apply) |
| **Основной репозиторий HH Ai** | [emildg8/HH_Ai](https://github.com/emildg8/HH_Ai) |
| **Лицензия** | MIT (см. [LICENSE](../LICENSE)) |

**В Steev193/hh-ru-apply ничего не публикуем** — только благодарность в документации по желанию.

## Что в HH Ai (поверх идеи)

- Профили `HH_PROFILE`, дашборд (анкета, темы, масштаб UI, плотность карточек)
- LLM-оценка, batch-отклики с отложенной анкетой, понятный журнал пропусков
- Harvest-фильтры, капча-wait, публичный релиз `npm run release:public`

При распространении zip/исходников можно кратко указать идею-основу и лицензию MIT.

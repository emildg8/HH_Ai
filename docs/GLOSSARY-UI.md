# Глоссарий UI (русский)



**Синхронизация:** `dashboard/public/dashboard-ux.mjs` → `GLOSSARY` · `glossaryLabel(key, uiMode, vars?)`.



| Термин (внутр.) | Простой режим | Расширенный |

|-----------------|---------------|-------------|

| FP / fpRejected | Ложные пропуски в отказах | FP в отказах |

| fp ok | Ложных пропусков нет | Ложных FP не найдено |

| off-target | Нецелевых откликов | Off-target |

| golden regression | Проверка эталонов не пройдена | Регрессия golden set |

| harvest | Поиск вакансий | Harvest |

| batch | Серия откликов | Batch |

| precheck | Проверка перед серией | Precheck |

| questionnaire | Анкета работодателя | Questionnaire |

| funnel | Статистика откликов | KPI / funnel |

| sync responses | Синхронизация статусов | Sync responses |

| sync chats | Обновление чатов | Sync chats |

| letter quality | Качество письма | Letter quality |

| letter score | Оценка письма | Letter score |

| targeting | Фильтр вакансий | Targeting |

| golden letters | Эталоны писем | Golden letters |

| golden targeting | Эталоны таргетинга | Golden targeting |

| auto-reject | Авто-отклонение похожих | Auto-reject |

| FP guard | Ложные пропуски в «Неподходит» | FP guardrail |

| FP suggest | Что добавить в правила | Срочные предложения для FP |

| FP toast | Ложные пропуски: {n}… | Найдены false positives: {n}… |

| batch FP confirm | …ложных пропусков (порог {fpMax}) | …false positives (порог {fpMax}) |

| workflow find/review/apply/track | Найти / Разобрать / Откликнуться / Следить | Workflow: find…track |

| service drawer | Сервисы и пакеты | Service drawer |

| job progress | Текущая задача | Job progress |

| rate limit | Лимиты откликов | Rate limits |

| precheck diff | Изменения настроек перед серией | Precheck prefs diff |

| UI trim hint | Поиск и отклики — слева в «Действия»… | UI trim: действия слева… |



При добавлении подписи в UI: сначала строка здесь, затем ключ в `GLOSSARY`.

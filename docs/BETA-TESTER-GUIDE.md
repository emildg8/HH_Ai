# Гид для beta-тестера

Спасибо, что пробуете HH Ai! Этот документ — сценарии на **15 / 30 / 60 минут**.

## Перед началом

- Прочитайте [PUBLIC-RELEASE.md](PUBLIC-RELEASE.md) — установка zip.
- Убедитесь: в архиве **нет** чужих ключей (`npm run setup:check` после install).

## Сценарий 15 минут (без hh.ru)

| Мин | Действие | Ожидание |
|-----|----------|----------|
| 0–5 | `install-portable.ps1` → `start-dashboard.bat` | дашборд открывается |
| 5–8 | очередь из 5 демо-вакансий | список не пуст |
| 8–12 | открыть DevOps / SRE → drawer | видны оценка, описание |
| 12–15 | Настройки → обзор вкладок | модалка без ошибок |

**Успех:** понятно, «что это за программа».

## Сценарий 30 минут (+ inbox)

Всё из 15 мин + :

| Мин | Действие | Ожидание |
|-----|----------|----------|
| 15–20 | Сервисы → Чаты (inbox) | есть демо-диалоги |
| 20–25 | открыть диалог с вопросом HR | видно «нужен ответ» |
| 25–30 | Настройки → Система | статус сервисов читаем |

Запишите: что было непонятно с первого взгляда.

## Сценарий 60 минут (+ свой hh.ru)

**Только если готовы** использовать свой аккаунт.

| Мин | Действие |
|-----|----------|
| 30–40 | `HH_PROFILE_RESUME_TITLE` + `npm run login` |
| 40–50 | `npm run harvest` или ручное добавление 1 вакансии |
| 50–60 | один тестовый отклик (не батч!) |

## Что писать в отзыве

1. **Версия** — файл `VERSION` в корне.
2. **Сценарий** — 15 / 30 / 60 мин, demo или live.
3. **Понятно** — 1–3 пункта.
4. **Непонятно / бесит** — конкретные экраны.
5. **Блокер** — не смогли продолжить (1–5).

Шаблон issue: GitHub → New Issue → beta-feedback (если доступен).

## Не нужно тестировать

- Платные LLM без своего ключа
- Массовый батч на сотни откликов
- Telegram без настройки бота

## Контакт

Вопросы по установке — через отправителя архива или GitHub Issues.

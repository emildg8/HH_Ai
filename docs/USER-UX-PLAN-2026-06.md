# План UX для рядового пользователя (2026-06)

**Цель:** меньше жаргона, понятные следующие шаги, безопасная отмена настроек.

| # | Проблема (взгляд пользователя) | Решение | Статус |
|---|--------------------------------|---------|--------|
| 1 | «FP», «false positives» — непонятно | Человеческие подписи: «ошибочно в „Неподходит“» | [x] |
| 2 | Случайно поменял настройки — как откатить? | Кнопка **«Отменить на вкладке»** (снимок при открытии/сохранении) | [x] |
| 3 | Precheck не объясняет, зачем пустой блок diff | Подсказка до/после первой серии | [x] |
| 4 | Отчёт батча — только цифры | Строка-итог простым языком + кнопки в настройки | [x] |
| 5 | Онбординг не исчезает после первого успеха | Скрытие после `done > 0` в последнем отчёте | [x] |
| 6 | В модалках видны команды `npm run …` | Перенос в `ui-expert-only` | [x] |
| 7 | «Сбросить раздел» путают с отменой | Подписи кнопок и title уточнены | [x] |
| 8 | Дубли кнопок (menubar / sidebar / toolbar) | UI trim: одна точка «Сервисы», действия слева | [x] |
